**Install**
- Clone this repo, then install: `pip install .`

**Usage**
- Run: `meow`
- It fills your terminal while preserving aspect ratio (contain).
- Debug overlay: `meow --debug`
- Fit mode: `meow --fit=contain` (default) or `meow --fit=cover`
- Pixel mode: `meow --pixel-mode=auto|braille|half|full` (default: auto)

Notes
- Inversion: rendering is intentionally inverted (dark filled; light blank).
- If a `silly-cat.gif` is in your current directory, it will be used; otherwise the bundled GIF is used.
